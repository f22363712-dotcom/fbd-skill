# Evidence cards

Use only the card types needed. Omit the entire card set when there is no decision-relevant finding.

## Discovery

- **Finding:** One-sentence observation.
- **Evidence:** Clickable files, line locations, commits, tests, or tracker items.
- **Why now:** Why this changes the live task or decision.
- **Suggested action:** One reversible next step.
- **Confidence / unknowns:** High, medium, or low, followed by the main uncertainty.

## Dissent

- **Current direction:** The assumption or plan being challenged.
- **Counterevidence:** Concrete repository evidence, not generic skepticism.
- **Failure mode:** What becomes costly or false if ignored.
- **Turn / stop option:** A specific redirect, subtraction, or stopping rule.
- **Reversal evidence:** What new evidence would justify continuing the original direction.

## Question

- **Decision blocked:** The concrete choice that cannot safely be made yet.
- **Known evidence:** What the repository already establishes.
- **Question:** One answerable question whose answer changes the next action.
- **Default if unanswered:** The safest reversible assumption, or `pause` when none exists.

## Recap

- **Original intent:** The initial problem or outcome.
- **Turning points:** Only decisions that changed scope, architecture, or validation.
- **Current truth:** What code and active documents support now.
- **Superseded belief:** An older statement that should no longer guide work.
- **Next review trigger:** A measurable event, not a calendar ritual unless timing itself matters.
