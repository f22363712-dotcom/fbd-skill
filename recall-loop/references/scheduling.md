# 间隔重复：排期规则与台账格式

## 阶梯

```
等级 L1  →  1 天
等级 L2  →  3 天
等级 L3  →  7 天
等级 L4  →  16 天
等级 L5  →  35 天
等级 L6  →  75 天   （到顶后不再加长）
```

## 判定与升退

| 结果 | 动作 |
|---|---|
| ✅ 对 | 等级 +1（最高 L6），`连续正确` +1 |
| ⚠️ 部分对 | 等级不变，`连续正确` 清零，下次 = 今天 + 当前间隔 |
| ❌ 错 | 等级回到 **L1**，`连续正确` 清零，下次 = 明天 |
| 新卡 | 直接记 L1，下次 = 明天 |

`连续正确 ≥ 3` 的卡，在 B 类弱项攻坚里优先级下调；`连续错 ≥ 2` 的卡优先级最高。

## 台账位置

默认在项目根目录下的 `复习台账.md`。查找顺序：

1. `--file <路径>` 命令行参数
2. 环境变量 `RECALL_LEDGER`
3. 当前目录（含子目录）里第一个 `复习台账.md`

只有一张总表，所有科目都在里面。格式必须严格保持（脚本按列解析）：

```markdown
| ID | 科目 | 卡片 | 等级 | 间隔 | 下次 | 上次结果 | 连续正确 |
|---|---|---|---|---|---|---|---|
| C-001 | 国际商务文化 | 权力距离衡量什么 | L3 | 7 | 2026-11-08 | ⚠️ | 0 |
| C-002 | 国际商务文化 | 高/低语境判断依据 | L1 | 1 | 2026-11-05 | ❌ | 0 |
```

- `ID`：`C-` + 三位数字，全局唯一，不复用
- `科目`：与题库文件名一致
- `卡片`：一句话摘要（不是完整题目，完整题目在题库里）
- `等级`：`L1`–`L6`
- `间隔`：当前间隔天数（整数）
- `下次`：`YYYY-MM-DD`
- `上次结果`：`✅` / `⚠️` / `❌` / `新`
- `连续正确`：整数

## 计算示例

今天是 2026-11-04，某卡 L2（间隔 3），今天答对：

→ 等级变 L3，间隔 7，下次 = 2026-11-11，连续正确 +1。

同一张卡今天答错：

→ 等级回 L1，间隔 1，下次 = 2026-11-05，连续正确 = 0。

## 查到期

```bash
python scripts/due.py                # 今日到期 + 逾期
python scripts/due.py --days 3       # 未来三天
python scripts/due.py --all          # 全表
python scripts/due.py --subject 国际商务文化
```
