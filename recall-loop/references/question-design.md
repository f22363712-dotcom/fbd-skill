# 检索题设计

目标：逼用户**从记忆里重建**，而不是从选项里**认出**。

## 为什么再认（recognition）不算数

看到四个选项时，大脑做的是「匹配」；闭卷回想时，做的是「检索」。两者调动强度差一个量级，
所以「看笔记觉得都懂」和「合上书说不出来」可以同时成立——后者才是真实掌握度。

## 六种高杠杆题型

| 题型 | 适用 | 模板 |
|---|---|---|
| **① 闭卷复述** | 定义、分类、维度 | 「不看材料，说出 X 的几个要素。」 |
| **② 机制解释** | 因果、过程 | 「X 为什么会导致 Y？中间缺了哪一步？」 |
| **③ 对比辨析** | 易混概念 | 「X 和 Y 的区别是什么？各举一例。」 |
| **④ 反例构造** | 边界条件 | 「造一个例子，它看起来像 X 但其实不是，并说明理由。」 |
| **⑤ 迁移应用** | 真实情境 | 「用 X 分析这个新场景，你会先看什么？」 |
| **⑥ 纠错** | 常见误解 | 「'……' 这句话错在哪？改成对的。」 |

## 出题五条约束

1. **一题一点**。要考两件事就出两题。
2. **答案可核对**。答案必须能落在用户材料原文上；落不到就标注「材料未覆盖」。
3. **无提示性措辞**。禁止「很明显」「主要」「首先想到」这类泄题词。
4. **不考记忆噪音**。人名年份只在考试确实考时才问；否则考机制。
5. **难度递增**。同一知识点：复述 → 解释 → 对比 → 反例。

## 反例（不要这样出）

- ❌「以下关于霍夫斯泰德五维度，正确的是：A/B/C/D」→ 再认
- ❌「请解释霍夫斯泰德五维度、霍尔的高低语境、克拉克洪的六维度」→ 复合题，且是复述清单
- ❌「权力距离是什么意思」→ 只要名词解释，没有迁移

## 正例

- ✅「不看材料，说出权力距离这个维度衡量的是**谁和谁之间**的什么差异。」
- ✅「如果一个团队里下属从不敢在会议上反驳上级，这是高权力距离还是低？你的判断依据是什么？」
- ✅「造一个例子：表面上像低权力距离，但其实是高权力距离。说明理由。」
- ✅「有人把单时制和多时制记反了。你会用什么一句话让他记住区别？」

## 卡片写法（写进题库）

```markdown
### C-012 · 权力距离
- 题型：机制解释
- 题：不看材料，说明权力距离衡量的是什么，并给出一个高/低权力距离的判断依据。
- 依据：<笔记路径> 第 N 节
- 答案（首次复习后补）：
```

**只写题目，不预写答案。**
