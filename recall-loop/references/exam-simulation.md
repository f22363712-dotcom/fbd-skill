# 模拟考（C 类）

定位：**pre-performance practice**——把备考当演出前的彩排，不是复习。
价值来自「和真实考试同构」：同样题型、同样时长、同样闭卷压力。

## 开始前必须问清四件事

1. **真实题型**：判断 / 选择 / 名词解释 / 简答 / 论述 / 计算？（各占多少分）
2. **时长**：真实考试多少分钟？
3. **范围**：哪几章 / 哪些章节明确不考？
4. **给分口径**：按点给分还是按整体？

**任何一项缺失就不要开始**，凭猜出的题型做的模考只会给出错误的安全感。

## 组卷

- 题量按真实考试配比缩减到能在时限内完成（一般 60–70% 题量，时间 = 真实时长）。
- 难度按真实分布：多数基础题 + 少量综合题 + 1 道拔高。
- 题型必须覆盖用户最容易丢分的那一类。
- **不泄题、不给范围提示**。

## 开考

只说三句话：

```
开始。共 N 题，限时 M 分钟。
全程不提示、不讲评，答完或时间到告诉我「交卷」。
```

然后**闭嘴**。用户中途问「这题是不是…」→ 只回「按你的判断写」。

## 批改

交卷后只输出：

```
总分：X / 100
用时：MM:SS

| 题 | 得分 | 丢分点 |
|---|---|---|
| 1 | 8/10 | 漏了「…」这一层 |
```

- **不展开讲解**。只标丢分点。
- 完整讲解放到**下一次会话**开头（这本身就是一次间隔重复）。
- 把错题转成卡片，写进题库 + 台账（L1，明天到期）。

## 复盘三问（考完当场问，用户自己答）

1. 哪一道你**以为会但其实不会**？
2. 哪一道是**会但没写完/没写全**（时间分配问题）？
3. 如果多得 10 分，最该从哪一类题里拿？

## 频率建议

- 冲刺期：每 2–3 天一次全真模考
- 平时：每周 1 次，只考「到期卡最密集」的那一章
